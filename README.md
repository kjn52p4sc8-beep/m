# My Memo

iPhone Safari向けの日本語メモアプリ。既存アプリを拡張した0.8.0です。React / TypeScript / Vite / Tailwind CSS / Dexie（IndexedDB）を使用し、サーバー・ログインなしで端末内に保存します。

## 起動と検証

Node.js 22.12以上、npmを使用します（この環境はNode.js 24）。

```sh
npm ci
npm run dev
npm run build
npm test
npm run test:e2e
npm run build && npm run test:pwa
```

開発サーバーは5173、本番確認は `npm run preview`。クラウドのChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`。Safari互換のWebKitは `npx playwright install webkit` 後に `npm run test:safari`。

この環境のWebKit配布元への通信は403で拒否されます。ChromiumのiPhone画面幅テストはSafari実機の代わりにはなりません。

## 操作

- ホーム：タイトル・本文1行・更新日時をコンパクトな一覧に表示。ピン留めしたメモを先頭に表示します。
- 右下の＋：1タップで通常メモを開き、本文へフォーカス。分類を選ぶ必要はなく、変更は自動保存されます。
- 編集画面下部：パレットで背景色、チェックリストで項目追加、共有アイコンで送信内容確認。背景色は白・黄色・ピンク・緑・青・紫。パレット→色の2タップで保存し、用途は自由です。
- 左スワイプ／「…」：確認後ごみ箱へ移動。12秒間「元に戻す」を表示します。右スワイプ：ピン留め／解除。編集画面の☆でも変更できます。
- 検索：右上の虫眼鏡から入力。タイトル・本文・タグ・URL等の横断検索。色フィルターと高度な条件は必要時に開きます。
- ToDo：下部から1タップ。追加・期限・通知・編集・チェック・完了項目の確認を維持しています。
- 分類・タグ：編集画面の折りたたみを開いて変更。フォルダ作成・名前変更・並び替えは設定→フォルダを管理。旧カテゴリ・フォルダは削除しません。
- 画像・音声・表・リンク：編集画面の折りたたみから追加・編集。旅行・貸し借り・URL専用作成は設定の作成メニューにあります。
- 設定：テーマ、任意の使い方ガイド、バックアップ、ごみ箱、オフライン状態。ごみ箱は30日以上保管し、30日後も自動削除しません。

## 文字編集

本文の選択範囲に黒・赤・青・緑・オレンジ・紫を指定できます。選択なしで色を指定すると以降の入力色になります。最後の色はこのブラウザに記憶します。黒はダークモードで明るい本文色になり、他の色も明暗に合わせて変わります。

本文は通常のtextarea、色は別の範囲情報として保存し、HTMLは保存・実行しません。「取り消す」は本文・色の変更を直近50回まで戻します（編集画面を閉じると履歴は終了）。文字列の検索・置換には専用の取り消しもあります。画像注釈のUndo/Redoは独立しています。

画面下の文字数はリアルタイム更新。通常は改行を除き空白を含む本文の文字数です。タップすると全文（改行・空白あり）、改行・空白なし、選択範囲の文字数と上限設定を表示します。上限は200/300/400/600/800文字、または1〜1,000,000の任意値。到達はオレンジ、超過は赤で表示し、入力は止めません。上限はメモごとに保存します。Intl.Segmenter対応ブラウザでは結合絵文字・濁点等を1文字として数えます。タイトル・表・装飾情報は本文の文字数に含めません。

## 旅行予算・貸し借り

旅行名はメモタイトル。旅行先・日程・予算・通貨を設定し、支出金額・カテゴリー・日付・メモを追加します。円換算の予算・支出・残金・使用率を表示します。通貨はJPY/USD/EUR/GBP/KRW/CNY/TWD/THB/AUD。為替は手入力で、予算と各支出にレート・適用日時を保存します。日時入力欄はUTCと明示し、履歴は端末の時間帯で表示します。1支出ごとに円単位へ四捨五入します。最新レートの自動取得はしません。

貸し借りは円建てで、相手・貸した／借りた・金額・日付・返済予定・メモを保存。一部返済、返済履歴、未返済残高・貸付／借入総額・完済表示に対応します。過剰返済は拒否します。誤った支出・返済記録は確認後に削除／取り消せます。金額は通貨の最小単位の整数で保存します。

入力フォームの「保存」で記録に追加した後、メモと一緒に自動保存されます。保存ボタンを押していないフォーム途中の内容は、画面移動・再読み込みでは復元しません。

返済予定はカレンダー用ICSを書き出せます。相手の名前・金額は含めません。カレンダーに取り込み、通知設定を確認してください。アプリからのバックグラウンド通知・プッシュ通知は未実装です。

## 保存と互換性

- 入力停止後500msで自動保存。戻る時は保存完了を待機し、失敗を画面に表示します。
- メモ本文等の未保存下書きはlocalStorageにも保持し、DBの内容と一致する場合だけ復元します。他の更新と競合した下書きを無条件に上書きしません。
- IndexedDBスキーマv9。v1〜v8から追加テーブル・インデックスのみで移行し、既存ID・本文・日時・画像を変換しません。背景色は任意フィールドで、未設定は白と表示します。
- メモ・フォルダ削除はごみ箱へ移動し、画像・音声も保持。復元可能です。完全削除は確認後に対象メモ・画像・録音を削除します。
- 使い方ガイドは設定から任意で表示。ホームの初回利用を妨げません。

保存先は同じオリジン（プロトコル・ホスト・ポート）のブラウザです。端末間の同期はありません。サイトデータ削除、ブラウザのストレージ回収、プライベートブラウズ終了、OSによる強制終了などに備え定期的にバックアップしてください。設定の永続ストレージ許可はブラウザによって拒否される場合があります。

## バックアップ

設定からJSONを保存・復元します。形式v8、旧v1〜v7も読み込めます。カテゴリー・フォルダ・メモ・タグ・リンク・チェック項目・表・文字色・背景色・文字数上限・お気に入り・旅行・貸し借り・ごみ箱・画像・注釈・録音・表示テーマを含みます。画像と録音はBase64です。

上限100MB。形式・参照・重複ID・金額・文字色・URL・画像／音声等を検証し、確認後、DB全体を一つのトランザクションで置き換えます。**マージではありません。復元前に現在のバックアップを保存してください。** 検証失敗・DBトランザクション失敗時は元のDBを保持します。DB復元後にテーマ設定の保存だけ失敗した場合は、その状態を明示します。最後のペン色・チュートリアル表示設定・未保存フォーム・ToDo通知済みの記録はバックアップ対象外です。ToDoの期限・通知設定、メモ単位のリマインダー設定と通知済み状態は含まれます。復元後、期限超過の通知が再表示される場合があります。

JSONは暗号化していません。ユーザーのブラウザデータはGitのバックアップに含まれません。新バージョンで使ったDBやJSONを、古いアプリへそのまま戻すことは保証しません。コードのロールバックとユーザーデータの復元は分けて行ってください。

## 画像・録音・表・リンク

- 画像：JPEG/PNG/WebP、1枚20MB・4000万画素以下、一度に10枚。長辺1920px以下のJPEGへ圧縮。透明部分は白、アニメーションは静止画。HEICは事前変換が必要です。
- 画像をタップして文字・手書き注釈を追加・編集・削除。注釈は「注釈を保存」で明示保存。原画像とは別に保存し、Undo/Redoは50操作。合成画像の書き出しは未実装です。
- 音声：HTTPSとマイク許可が必要。MediaRecorderの対応形式を検出して端末内へ録音。1件10分／20MB。保存失敗時は再試行・破棄を選べます。OSによるアプリ強制終了・画面ロック時の保存完了は実機確認が必要です。
- 表：最大50表、各100行×20列。表内だけ横スクロールできます。
- 動画・Web：HTTP/HTTPSのみ、認証情報入りURLを拒否。元サイトをnoopener noreferrer付きで開きます。動画取得・再配信、サムネイル自動取得、埋め込み再生は行いません。

## PWA・iPhoneでの確認

本番ビルドをHTTPSのルート `/` に配置し、オンラインで初回起動。設定でオフライン準備完了を確認すると、メモとローカル添付をオフラインで利用できます。開発サーバーではService Workerを登録しません。更新は設定から適用し、編集中に自動再読み込みしません。

Safariの共有メニューから「ホーム画面に追加」。公開前に以下を実機で確認してください。

1. 日本語変換・絵文字・範囲選択・色変更、文字数上限と取り消し。
2. キーボード表示／非表示、縦横回転、長文入力中のスクロール、下部の文字数・戻るボタン。
3. 写真選択・手書き・録音・再生、画面ロック後の復帰。
4. バックアップをファイルアプリに保存・復元、旧データの読み込み。
5. 機内モードで旅行支出・返済を登録し、アプリ再起動後に残ること。
6. ダークモード、320〜430px相当の幅、セーフエリア、カレンダーファイルの取り込み。

## 0.4.1：オフライン機能の案内

HTTPSの安全な接続とService Worker対応を別々に判定します。HTTPSでもアプリ内ブラウザ等で機能が使えない場合はSafariで直接開く手順を表示します。制限のあるブラウザでは、設定からURLのコピーとオンライン時の通常再読み込みを利用できます。通常再読み込みではDBやサイトデータを削除しません。ブラウザ変更では保存先が異なるため、元の環境のJSONを保持して移行してください。オフライン非対応の環境を、アプリ側で強制的に対応させる変更ではありません。

## 0.5.0：ToDo通知・他アプリとの活用

通知は任意です。ToDoの「期限・通知」で期限当日（指定時刻）、前日（同時刻）、自由な日時を選びます。時刻は端末の時間帯で入力し、UTCで保存します。通知を有効にするときだけ端末の許可を求めます。

**アプリを開いている間だけ予定を確認します。閉じている間の配信は未実装です。** 次に開いた際、通知時刻を過ぎた未完了項目を表示します。端末通知が使えなくてもアプリ内で確認できます。期限変更・完了・削除・通知オフを反映し、同じ項目・通知時刻の重複表示を防ぎます。入力中は通知確認を止めます。iPhoneの端末通知はiOS/iPadOS 16.4以降、HTTPS、ホーム画面に追加したPWAでの許可が必要です。実機での配信は未確認です。

他アプリからはURL・テキストをコピーし、「設定 → 作成メニュー → URL・テキストを保存」に貼り付けます。クリップボード読み取りを許可しない場合は入力欄を長押しして貼り付けてください。URLのサービス名を表示し、元のページへ移動できます。内容・動画・サムネイルを外部から自動取得しません。iPhone SafariはWeb Share Target非対応のため、他アプリの共有先にMy Memoを直接追加する機能は提供していません。

メモ編集画面の共有アイコンで送信内容を確認・編集し、iPhoneの共有メニューを開くかコピーします。対応するのはタイトル・本文・チェック項目・リンクです。画像・録音・表・旅行予算・貸し借り記録を自動添付しません。共同編集・クラウド共有とは別の、文章の受け渡しです。

## 0.8.0：日常利用・リンク連携

- メモ編集の「リマインダー」で日時設定・変更・解除。既存ToDo通知と一緒に、アプリが表示されているときだけお知らせします。通知済み状態を保存します。編集画面・ダイアログ表示中は通知を止め、閉じた後に確認します。バックグラウンド配信はありません。
- 検索用の正規化文字列を再利用し、結果を50件ずつ追加表示します。タイトル・本文・タグ・URLに加えて、取得したリンクのタイトルも検索できます。
- ＋から通常メモを作り、本文へURLをペーストするとリンクも保存します。本文の文字や元のURLは残ります。手入力したURLは「画像・音声・表・リンク」から追加できます。
- 「URL・テキストを保存」では保存済みURLを検出。既存メモを開くか、別メモとして残すか選べます。同じメモへの重複ペーストはリンクカードを増やしません。
- YouTubeの対応動画は「プレビュー → YouTubeに接続して取得」で実際のタイトルを取得できます。接続前に送信先を表示。画像は別の「サムネイルを表示」操作で読み込み、再起動後は再び非表示です。取得失敗時や他サイトではURLを利用してください。
- 対応ブラウザ向けのWeb Share Target受信画面を追加。iPhone Safariでは受け取り先に表示できないためコピー・ペーストを使用します。受信しただけでは保存しません。GET方式の受信内容はブラウザ履歴やホストのアクセス記録に残る可能性があります。
- DB v9 / JSON v8は任意フィールド追加。旧データを一括変換せず、色・チェック項目・分類・添付を維持します。プレビューはタイトル・サイト名・画像URL・取得日時を保存し、外部画像の実体はJSONに含みません。

詳細は [共有・プレビューの対応範囲](docs/implementation/phase3-compatibility.md) と [クラウド同期設計](docs/implementation/cloud-sync-design.md)。クラウド同期は設計のみで、利用可能とは表示していません。
