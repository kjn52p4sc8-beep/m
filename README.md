# My Memo

iPhone Safariを主な対象とする日本語の個人用メモアプリ。React / TypeScript / Vite / Tailwind CSS / Dexie（IndexedDB）で作成しています。

## 起動

Node.js 22.12以上（この環境では24.19.0）、npmを使用します。

```sh
cd /workspace/m
npm ci
npm run dev
```

開発サーバーはポート5173で起動します。ビルドは `npm run build`、ビルド結果の確認は `npm run preview`。

## Netlifyでの公開

リポジトリ内の `netlify.toml` にビルド設定を保存しています。NetlifyでGitHubの `kjn52p4sc8-beep/m` をインポートし、公開対象のブランチとして `release/my-memo` を選択します。ベースディレクトリは空欄、ビルドコマンドは `npm run build`、公開ディレクトリは `dist`、Node.jsは24です。アプリ用の環境変数やAPIキーは不要です。

デプロイ完了後のHTTPS URLをiPhone Safariで開き、共有メニューから「ホーム画面に追加」してください。ホーム画面から起動してテスト用メモを作成し、保存済み表示後に再起動して残るか確認します。オフライン利用は設定で準備完了を確認してから試してください。

公開されるのはアプリ本体で、端末内のメモや写真はGitHubやNetlifyへ送信されません。以前のURLで作ったデータを移す場合は、元のアプリでJSONバックアップを保存し、新しいURLで復元します。復元は移行先の全データを置き換えます。今後の更新は同じNetlifyサイト・同じURLで行ってください。

## Phase 1〜3で実装した機能

- お金・勉強・仕事・生活の2列カテゴリーカード、カテゴリー別の色とアイコン。
- 初回に指定の16フォルダを作成。追加・名前変更・削除確認・上下ボタンでの並び替え。
- メモの作成・編集・削除確認、保存先変更、作成日時・更新日時。
- 入力停止後500msの自動保存。戻る操作時は保存完了を待機。保存失敗時は編集内容を保持して再試行できます。
- IndexedDBのスキーマv2（既存v1のメモを保持して移行）、UUID、再読み込み後の復元。フォルダ削除と配下メモ削除はトランザクションで処理。
- カテゴリー横断検索。タイトル・本文・タグ・リンクタイトル・URL・リンクタグが対象。空白区切りはAND検索、英字の大小と全角英数を正規化。
- メモとリンクのタグはカンマまたは読点区切り。
- 動画・WebリンクのURL、タイトル、タグ。HTTP/HTTPSのみ許可し、認証情報を含むURLを拒否。外部リンクは `noopener noreferrer`。
- ライト・ダーク・端末テーマ、モバイル下部ナビ、セーフエリア、44pxタップ領域。

埋め込み再生は未実装です。すべて元サイトを開く方式で、動画・画像・サムネイルを自動取得しません。

## データについて

ログインやサーバーは不要です。メモは同じオリジン（プロトコル・ホスト・ポート）のブラウザ内に保存されます。別端末・別ブラウザには同期されません。サイトデータ削除やプライベートブラウズ終了、ブラウザによるストレージ回収で失われる場合があります。保存中のタブ強制終了は保証できません。「保存済み」を確認してください。

設定から永続ストレージの許可を要求できます。ブラウザによって許可されない場合があります。許可されても手動削除への対策にはならないため、定期的にバックアップしてください。

## 検証

```sh
npm run build
npm test
npx playwright install chromium webkit
npm run test:e2e
npm run test:safari
npm run build && npm run test:pwa
```

ブラウザが既にあるクラウド環境では以下も使用できます。

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

- Vitest: データ初期化、フォルダ操作、メモ再接続・復元、削除連動、URL検証、検索。
- Playwright: フォルダCRUD、メモCRUD・保存・再読込、リンク、検索、テーマ、保存失敗と復旧、320px表示。
- Chromiumのモバイル設定はiPhone実機Safariの代替ではありません。
- 操作テストは専用ポート5180で開発サーバーを起動します。既存サーバーを再利用しないため、ポート5173で本番プレビューを開いていても混同しません。
- このクラウドではPlaywright配布元 `cdn.playwright.dev` が403で拒否され、WebKitは未検証です。通信可能な開発機で `npm run test:safari` を実行してください。

## iPhone実機での確認

1. このリポジトリを手元のMac/PCで起動し、同じWi-FiのiPhoneから到達できるようにします。
2. iPhoneからはlocalhostではなくMac/PCのLANアドレスを使います。UUID等のブラウザAPIに安全なコンテキストが必要なため、iPhoneが信頼する証明書を設定したHTTPSのローカルリバースプロキシ経由でアクセスしてください。
3. Safariの通常タブでカテゴリー→フォルダ→メモを作り、「保存済み」後に再読み込みして残ることを確認します。
4. キーボード表示時、縦画面、ダークモード、長いタイトル、フォルダ並び替え、削除キャンセル、タグ・動画URL検索を確認します。

クラウド環境のポートへiPhoneから直接接続できるとは限りません。外部公開は別途許可を得て行います。

## Phase 4〜6の追加機能

### 画像

メモの「画像を追加」からJPEG・PNG・WebPを選択します。1枚20MB以下・4000万画素以下、一度に10枚まで。ファイル形式・ヘッダー・デコード結果を検証し、長辺1920px以下のJPEG（品質0.82）として端末で保存します。透明部分は白、アニメーションは静止画になります。HEICは事前にJPEGへ変換してください。画像データはIndexedDBのattachmentsテーブルにBlobで保存し、メモ・フォルダ削除時に連動削除します。画像の追加は処理完了時に保存されます。

### 画像の文字・手書き注釈

画像をタップしてプレビューを開きます。「文字を追加」で画像上をタップし、文字を入力できます。「手書き」では指・マウスで線を描けます。注釈一覧から選び、文字・位置・色・サイズ、線の色・太さを編集・削除できます。Undo/Redoは直近50操作まで、注釈は1枚500個、線は各2万点までです。

**注釈は「注釈を保存」で明示的に保存します。** 閉じる際の未保存変更は確認します。原画像への焼き込みはせず、編集可能な注釈データを保存します。再読み込み・バックアップ復元後も編集できます。文字は単一行です。画像と注釈を合成したファイル書き出しは未実装です。

### バックアップ・復元

設定の「バックアップを保存」でメモ・フォルダ・カテゴリー・画像（Base64）・注釈を含むJSONをダウンロードします。「バックアップを復元」で内容を検証し、件数表示と確認後に**全データを置換**します。マージではありません。復元前に現在のデータをバックアップしてください。失敗時はトランザクションで元のデータを維持します。検証中はDBを書き換えません。

JSON形式バージョンは1、ファイル上限100MBです。画像の内容・サイズ、参照先、ID重複、URLスキーム、注釈を検証します。バックアップは暗号化されていません。OSのファイル保存が完了したことを確認してください。複数タブで同時に編集・復元する運用は対象外です。

### PWA・オフライン

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

開発用 `npm run dev` ではService Workerを登録しません。本番ビルドをHTTPS（または開発機のlocalhost）で開くとアプリ資源を保存します。初回オンライン読込とService Workerの準備完了後、メモ・画像・注釈はオフラインで利用できます。設定の「オフライン準備・更新を確認」で状態を確認してください。外部リンク先の動画などはキャッシュしません。

iPhone Safariでは共有→「ホーム画面に追加」。PWAはオリジンのルート `/` への配置を前提とします。サブパス配信は未対応です。更新は設定から確認して適用します。編集途中に強制的な自動再読み込みはしません。サイトのキャッシュを削除した場合はオンラインでの再読込が必要です。

## iPhone Safari向けの画面調整

- 入力欄・選択欄の文字は16px以上にして、フォーカス時のSafari自動ズームを防ぎます。ピンチズームは禁止していません。
- 編集中の「戻る」「保存状態」「削除」を上部に固定。本文は高さを抑え、本文内とページの両方をスクロールできます。
- Visual Viewportの高さと入力フォーカスからキーボード表示を検知します。表示中は下部メニューを隠し「キーボードを閉じる」を表示。閉じても入力内容を保持し、通常の自動保存が続きます。
- ダイアログはキーボードを除いた表示領域に収まり、中身だけスクロールします。背景を固定し、閉じると元のスクロール位置に戻します。一覧→メモ→戻るでも一覧の位置を保持します。
- ノッチ・ホームインジケーターに加えて横向きの左右セーフエリアへ対応。主な操作は44px以上のタップ領域です。
- 検索は検索用キーボード、URLはURL用キーボードと自動大文字化OFF。画面を開いただけでキーボードが出る自動フォーカスを減らしました。

自動テストではVisual Viewport縮小・オフセットを模擬し、セーフエリアを47px（上）・34px（下）として検証しています。これはiPhone実機のキーボード・Safariアドレスバー・日本語変換候補の挙動を完全に再現するものではありません。実機では以下を確認してください。

1. Safari通常タブとホーム画面版で本文・タグ・URLを入力し、変換候補を表示したまま画面最下部へ移動する。
2. キーボードを閉じても入力内容が残り、下部メニューが復帰する。
3. 長い本文と画像注釈の入力中に縦横を切り替え、ボタンが隠れないことを確認する。
4. 下までスクロールしてダイアログを開閉し、背景や一覧の位置が変わらないことを確認する。
5. 写真の拡大・ピンチズーム・日本語変換と、ブラウザのアドレスバー開閉を確認する。
