# My Memo 0.11.0 — AI文章アシスタント

2026-11-06。既存React/TypeScript/Dexieエディタを拡張。追加のnpm依存はありません。IndexedDB v11 / JSONバックアップv10を維持し、データ移行・初期化はしません。

## 実装

- 編集ツールバーに小さな「AI」。ToDoチェック・文字色・背景色・Undo・共有・挿入設定を維持。320〜430pxで44pxの操作領域を確認。
- ボトムシートに要約、丁寧な文章、敬語変更、校正、翻訳。選択した機能の設定だけを表示。要約7種類、文体7種類、ビジネス/学校/日常の用途、日本語・英語翻訳。
- 初回送信同意、送信文章確認、通信中表示、二重実行防止、キャンセル。本文または選択範囲だけを送信。
- 元の6色の文字列をトークンで保護。欠落・改変・重複をサーバーとブラウザで検査。不整合時は原文を変更しない。太字・下線は既存エディタにないため新設しない。
- 結果は確認後にコピー・挿入・置換。文字色付き結果を描画してもHTMLとして実行しない。クリップボード非対応時は選択コピー欄を開く。
- 適用前の本文・色照合とDBトランザクションで別タブ更新・削除を検出。タイトル、タグ、分類、ToDo、画像、背景色等の他データを置換しない。AI適用を既存Undoの1ステップに統合し、Redoも対応。
- Netlify FunctionsからOpenAI Responses APIへ接続する実装。秘密キーはサーバー環境変数のみ。入力長・出力長・処理時間制限、HTTPエラー対応、`store:false`、本文の独自ログ保存なし。
- Upstash Redisの原子的な日次共有制限（既定サイト全体20回、IP単位5回、連続10秒）。制限を確認できない場合はAI停止。公開・未認証のため第三者に利用枠を消費される可能性と費用上限の範囲を設定手順に記載。
