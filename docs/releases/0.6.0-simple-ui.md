# My Memo 0.6.0：一覧と入力を中心にしたUI改善

2026年10月30日。既存0.5.0のReact / TypeScript / Vite / Tailwind CSS / Dexieを継続使用。新規依存なし。

## 変更と操作

- ホームはMy Memo・検索・設定とメモ一覧。大型検索欄、カテゴリ切り替え、件数見出し、ToDoカード、重複した作成ボタンを撤去。薄い境界線と1行の本文抜粋、更新日時で表示。お気に入りはピン留めとして先頭に並べ、同じメモを二重表示しない。一覧の30件制限も外し、既存メモへそのままアクセスできる。
- 下部はメモ・ToDo・＋。ToDoを1タップで開ける導線を維持。ホームにはToDo入力や通知設定を重複表示しない。
- ＋からフォルダ選択を挟まず即座に編集画面を表示。本文へ同期的にフォーカスし、ユーザー操作に連動してキーボードが開ける構造へ変更。既存DBへの初回保存とその後の入力保存はEditorのキューで処理し、初回保存が後から本文を上書きしない。
- 背景色は白・黄色・ピンク・緑・青・紫。編集中に下部パレット→色で2タップ、自動保存。色と用途・従来のカテゴリは結びつけない。ライト／ダークそれぞれの淡い配色。320pxでは3列×2行で44px以上の色ボタンを確保。
- 左スワイプの削除・確認・12秒の取消を再利用。右スワイプでピン留め／解除を表示。誤クリック抑止・縦スクロールとの方向判定を維持。編集画面の☆からもピン留めできる。
- 検索アイコンで検索欄にフォーカス。横断検索・ハイライトは維持し、色フィルターとカテゴリ／フォルダ／タグの高度な条件は閉じた状態から必要時のみ開く。
- 編集画面上部の分類選択を「分類・タグ」に折りたたみ、本文の前に操作を挟まない。画像・音声・表・URLは「画像・音声・表・リンク」に集約。本文の文字色、文字数・上限、取り消し、検索置換を維持。下部のチェックリストアイコンは項目を直接追加してフォーカス。共有は下部から内容確認後に実行。
- フォルダ管理は設定→フォルダを管理、旅行・貸し借り・URLの専用作成は設定→作成メニューへ移動。少数の主要操作を優先するため、これらの補助機能は従来より入口が1段深くなる。説明ガイドは初回ホームに自動表示せず、設定から任意で表示。

## 操作性の比較

同じ8件のテストメモ（本文あり、ToDoなし、ガイド非表示）、Chromiumの390×844 CSS pxで比較。

| 項目 | 0.5.0 | 0.6.0 |
| --- | --- | --- |
| 最初のメモの上端 | 291px | 64px |
| 1行の高さ | 約131px | 76px |
| 下部バーに隠れず全体が見えるメモ | 3件 | 8件 |
| ＋から新規作成 | 1タップ、保存後に画面遷移 | 1タップ、即座に本文フォーカス |
| 背景色変更 | 機能なし | 2タップ |
| 検索開始 | 1タップ＋入力欄の選択 | 1タップで入力欄にフォーカス |
| ToDo一覧 | 1タップ | 1タップを維持 |
| チェックリスト追加 | 本文より下まで移動して追加 | 固定の下部アイコンから追加 |

測定はブラウザ内のCSSピクセル。実機のアドレスバー、文字サイズ、セーフエリアや表示内容により件数は変わる。計測値は[measurements.json](0.6.0-review/measurements.json)、[変更前](0.6.0-review/comparison-0.5.0.png)・[変更後](0.6.0-review/comparison-0.6.0.png)を保存。
