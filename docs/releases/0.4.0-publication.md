## 公開と確認の状況

ユーザーから「JSONを保存できた」と確認を受領済み。公開の許可とバックアップ確認が揃ったため、検証済みの変更を`release/my-memo`へfast-forwardで統合し、GitHubへpushする段階へ進みます。旧公開コードのバックアップブランチは維持します。ユーザーのiPhone内データや保存したJSONにはアクセスしていません。

iPhone実機での日本語キーボード・録音・写真選択等の検証は未実施です。シミュレーションと区別します。

Netlify公開URLとGitHubデプロイ状態APIは、この実行環境の通信制限で403になります。Netlify管理用の連携／トークンも設定されていません。そのためGitHub pushとNetlifyの公開完了は別々に確認する必要があります。NetlifyのGit連携が未設定なら、既存サイトで公開ブランチ `release/my-memo` を接続するか、検証済みZIPの内容を手動でデプロイします。新しいサイトを作るとオリジンが変わるため、既存サイトへ更新します。

## 更新時のiPhone操作

1. 現在の公開アプリでJSONを保存。空の端末の場合は不要。
2. 公開後、同じURLの設定で「オフライン準備・更新を確認」→「更新して再読み込み」。
3. 設定のバージョン0.4.0、旧メモ・画像・テーマを確認。
4. 確認用メモを編集し「保存済み」を待って再起動。続いてオフラインでも残ることを確認。

表示が古い場合もSafariのサイトデータを削除しないでください。メモの保存領域まで削除されるためです。
