# 0.8.0：PHASE 2・3 実装報告

作業日：2026-10-31。既存のReact / TypeScript / Vite / Tailwind CSS / Dexie / PWAを拡張。依存ライブラリは増やしていません。PHASE 1の1タップ作成・色・スワイプ・コンパクト一覧は維持しています。

## 実装と操作

- PHASE 2：メモ単位のリマインダー日時・変更・解除・通知済み状態を保存し、既存ToDo通知と統合。アプリ表示中のみ通知。権限要求中に編集を離れた場合は、後から保存内容を変えません。
- PHASE 2：検索用文字列をメモ更新時に正規化し、入力ごとに再計算しません。検索結果は最初50件、以後50件ずつ表示。5,000件のノートで検索結果を確認。
- PHASE 2：ピン留め、チェック項目、文字編集、画像・音声・表、JSON保存・復元は再利用。クラウド同期は [設計文書](../implementation/cloud-sync-design.md) にまとめ、同期できる表示は追加していません。
- PHASE 3：本文へのURLペーストで、安全なHTTP/HTTPSリンクを保存。文章を残し、同じメモ内の重複リンクを増やしません。リンクは編集画面で折りたたみを開かずに表示します。
- PHASE 3：URL保存画面・共有受信画面で保存済みリンクを検出し、既存メモを開く／別に保存を選択。YouTubeの短縮URLと通常URLも同じ動画と判定。既存メモを自動上書きしません。
- PHASE 3：YouTube公開動画のoEmbedプレビューを明示操作で取得。利用者のタイトルと元URLは変更せず、取得したタイトル・サイト名・画像URL・取得日時を保存。画像表示は別操作。取得不能時は元URLを維持。
- PHASE 3：対応ブラウザ向けWeb Share Targetを追加。受信内容を確認してから保存。iPhone Safariは共有受信非対応なのでコピー・ペーストを案内。既存の外向け共有・コピーは維持。

新規作成・既存メモを開く・検索開始は1タップ、背景色は2タップのまま。URL保存は旧「設定→作成メニュー→URL保存→貼り付け→保存」から「＋→本文へ貼り付け（自動保存）」でも可能になりました。OSのペーストメニュー操作は別に必要です。チェックリスト追加・ToDoへの入口を維持し、追加機能の設定は折りたたんでホームへ増設していません。

## 未実装・設定が必要なもの

- 認証・クラウド同期・共同編集：サーバー、認証、アクセス制御、費用上限の設定が必要。設計のみです。
- アプリを閉じている間の通知：Web Push配信サーバー／スケジューラーが必要。現状は次回表示時に期限超過を表示。
- iPhoneの共有先として直接受け取る：Web Share Target非対応。将来のiOS Share Extension等が必要。
- Instagram / TikTok / X等の投稿情報・サムネイル自動取得：API・権限・CORS条件を確保していないため未対応。URLは保存・検索・外部表示可能。
- 外部サービスの新規契約・アカウント作成はしていません。YouTubeへの接続は利用者が選びます。詳細・費用・GET受信の履歴上の注意は [対応範囲](../implementation/phase3-compatibility.md) に記載。
