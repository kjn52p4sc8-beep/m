# My Memo 0.10.1 — 編集のUndo・Redo

2026-11-05（日本時間）。既存のReact・textarea・別管理の文字色範囲を維持し、左から2番目の矢印を自然な編集単位で戻せるよう改善しました。追加ライブラリ・DB移行はありません。

## 変更内容

- 矢印アイコン・位置・サイズを維持。「取り消す」（ツールチップ「元に戻す」）で本文・タイトル・文字色の直前の編集を取り消します。メモを削除する処理には接続しません。履歴なし・変換中は無効化し、既存の薄い表示を使います。
- 同じ位置からの連続入力・連続Backspace/Deleteは、1秒以内の連続操作をまとめます。入力方向の変更、範囲置換、改行、貼り付け、カーソル移動、フォーカス移動、文字色変更は別の操作として扱います。
- 日本語の変換開始から確定までを1ステップとし、確定後の重複inputイベントで履歴を増やしません。変換中の自動保存・標準描画への既存対応を維持しています。
- 最大50ステップ。メモの編集画面ごとに独立し、閉じた時に履歴は終了します。自動保存では履歴を消しません。再読み込み後は保存された本文・色を読み込み、Undo履歴は空になります。
- Undo/Redoでカーソル・選択範囲・選択方向・入力欄内のスクロール位置を復元します。実際のiOS IMEの挙動は未検証です。
- Redoは既存の「挿入・設定 → やり直す」。下部の操作ボタンを増やしていません。新たな編集をするとRedo履歴を破棄します。コピーなど文字を変更しない操作では履歴を増やしません。
- Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+YとブラウザのhistoryUndo/historyRedo入力イベントを同じ履歴へ接続。別のエディターライブラリは未使用で、textarea単独の履歴では外部管理の文字色を戻せないため、既存のアプリ履歴を置き換えて一本化しました。
- Undo/Redoの結果も通常の自動保存・下書き保護・保存失敗表示を通します。画像・録音・リンク・チェックリスト・表・分類等のデータはUndoの対象にせず保持します。貼り付けによって登録されたリンクも別データとして保持します。

調査時点で、矢印はコード上はUndoでした。しかし履歴が入力イベント単位で、選択位置の復元やRedoがありませんでした。今回その履歴管理を改善しています。単一の入力操作しかない新規メモではUndoで本文が空になることがありますが、メモ自体・添付・その他の保存データを削除する操作ではありません。
