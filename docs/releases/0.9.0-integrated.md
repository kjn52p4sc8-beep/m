## 操作の改善

- 新規作成・既存メモを開く・検索開始・ToDoチェックは各1タップを維持。
- 共有は従来の独自確認画面→共有ボタンの2操作から、共有アイコンの1タップへ。標準共有先の選択はOS側で別途行います。
- 編集画面の背景色はパレット→色の2タップ。ホームでは右スワイプ→色変更→色選択。
- ピン留めは長押し→選択。「…」でも同じメニューを開けます。
- 削除は左スワイプ→削除→確認。既存AGENTS.mdの削除確認ルールと誤操作防止を維持しました。12秒の取り消し、ごみ箱から復元、30日後も自動削除しない既存仕様です。
- 設定は目的の行から1タップで開きます。バックアップなどは別パネルに分離し、通常の設定一覧を短くしました。
- タイマーの時間/分/秒は端末標準のselectを使用しています。iOS時計アプリ独自のホイール描画を再実装したものではありません。
