## 第2段階：端末内の編集・メディア機能

文字数、タイトル／本文内の一致位置への移動、文字列の一括置換と取り消し、編集可能な表、録音・再生・削除を追加。録音は対応MIMEを判定し、20MB／10分を上限に端末へ保存。権限拒否を表示し、保存失敗時には録音を画面に保持して再試行できる。音声の外部送信は行わない。録音中は戻る・メモ削除を禁止し、非表示時は停止・保存を試みる。

DB v4は録音テーブルを追加。JSON v3に表・録音を含め、旧v1/v2も読み込む。ごみ箱では録音を保持し、完全削除時のみ連動削除。表は50個、各100行20列、セル1万文字まで。

検証：単体54件成功。初回ビルドではテスト用のNode Buffer型参照がブラウザ向け型設定に合わず失敗。Web標準のBase64処理へ修正してビルド成功。操作38件、本番PWA3件がすべて成功（計95ケース）。音声の操作テストは合成マイク入力からMediaRecorderで実際にエンコードしたデータを使用し、バックアップ復元後の再生まで確認。iPhone実機マイクや画面ロックの検証とは区別する。
