## 実装済み

| 分類 | 内容 |
| --- | --- |
| UI | 白背景・黒文字・深緑アクセント、ダーク表示。コンパクトなカテゴリー切替、最近開いたメモ、お気に入り。通常メモは＋の1タップ、旅行／貸し借りは種類→選択の2タップで作成 |
| 本文の文字色 | 6色、選択範囲・続けて入力する色、最後のペン色記憶、色の永続保存、明暗モード対応。本文と色を分離しHTMLを実行しない |
| 文字数 | 下部に常時表示、通常は改行なし・空白あり。日本語・結合絵文字等の計数、全文・空白なし・選択範囲の詳細、上限のプリセット／自由入力、到達・超過色、上限後も入力可能 |
| 取り消し | 本文・色の直近50操作、文字列置換の取り消し。既存の画像注釈Undo/Redoも維持 |
| 旅行予算 | タイトルを旅行名として利用、旅行先・日程・予算・通貨、支出履歴、残金・使用率、各支出の手入力レートと適用日時、円換算、オフライン保存 |
| 貸し借り | 相手・方向・金額・日付・予定日・メモ、貸付／借入合計、未返済残高、一部返済、履歴、完済、返済の取り消し。返済予定のICS書き出し |
| チュートリアル | 空の新規環境で4項目の短いガイド、スキップ／終了後は非表示、設定から再表示 |
| 互換性 | DB v5への追加のみの移行、バックアップv4と旧v1〜v3の読込、旧版の未保存下書き復元。色・上限・旅行・返済・お気に入りもJSON復元 |

既存のカテゴリー・フォルダ、メモ・リンク・タグ、チェックリスト、ごみ箱、検索、画像／注釈、音声録音、表、PWAを維持しています。通常のメモ編集は500msの自動保存、旅行設定・支出・貸し借り・返済のフォームは各保存ボタンで登録後に自動保存します。未登録のフォーム途中の値は再読み込み後には復元しません。

## 未実装・制約

- Apple／Google／メール認証、クラウド同期、個別／グループ共有、招待・QR、権限、同時編集と履歴・共有解除：サーバー基盤・プロバイダー設定がなく未実装。画面では未実装と明示。公開URLを渡しても個人メモは共有されません。
- 旅行・貸し借りの共有連携：任意のメモデータとして保持できる構造ですが、実際の共有は未実装。
- AI文字起こし・要約・ToDo抽出・タグ提案：同意・料金・サーバー側API設定が必要で未実装。
- 為替の自動取得、アプリからのバックグラウンド返済通知：未実装。現在は手入力とカレンダー書き出し。
- 為替日時入力はUTC表示。履歴は端末時間帯。円換算は記録ごとの四捨五入なので、合計を一括換算した金額とは丸め差が出る場合があります。
- 文字数は本文のみ。Intl.Segmenterを優先し、古いWebKit向けに一般的な結合文字・絵文字の代替計数を備えています。非対応環境で全言語のUnicode書記素規則を完全実装するものではありません。
- iPhone実機Safariでの日本語IME・写真・録音・カレンダー取込は未確認。クラウドのWebKit実行ファイルも未インストール（配布元への取得は以前403）。
- Canva連携ツールがなく直接編集は実施できません。ユーザーの参考画像と既存のデザイン検討を基にコードへ反映しました。参考画像をCanvaから書き出して再調整に利用できます。

外部サービスの費用・保護・設定手順は [external-services.md](external-services.md)。サービス作成・契約・APIキー設定・データ送信は行っていません。
