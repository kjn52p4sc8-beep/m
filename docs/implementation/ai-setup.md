# My Memo AI文章アシスタントの設定

この機能は **Netlify Functions + OpenAI Responses API + Upstash Redis** を使います。新しい有料サービスの契約・APIキー発行・環境変数登録はこの作業では行っていません。設定が揃わない状態では「未設定または停止中」と表示し、生成できるようには見せません。`npm run dev` / `vite preview` はFunctionsを実行しないため、AIの接続確認は失敗します。通常のメモ編集は利用できます。

## 費用と送信データ

- OpenAI APIは入力・出力トークンに応じた従量課金で、ChatGPTの有料契約とは別です。既定モデルは `gpt-4.1-mini`。単価・無料枠は変わるため、契約前に [OpenAI料金](https://openai.com/api/pricing/) を確認してください。
- [Netlify料金](https://www.netlify.com/pricing/) のFunctions/リクエスト利用枠と [Upstash料金](https://upstash.com/pricing/redis) のRedis利用枠も確認してください。無料で無制限には使えません。
- 原則1回の送信は本文8,000 UTF-16コード単位以内（絵文字等は複数になることがあります）、最大出力4,096トークン。長文は一部を選択して利用します。
- 本文または選択範囲、保護する文字列と色、選んだ機能と文体・相手との関係をサーバー経由でOpenAIへ送ります。メモタイトル・画像・音声・他のメモ・IDは送信しません。
- 初回に同意チェックが必要です。同意はブラウザ内に記録し、「送信・料金について」から撤回できます。毎回「この文章を送信して生成」を押すまで本文は送信しません。
- アプリのFunctionsは本文を保存・ログ出力しません。`store:false` でOpenAIに送信しますが、プロバイダーの不正利用監視などは [データ保持ポリシー](https://platform.openai.com/docs/guides/your-data) に従います。プラットフォームのアクセスログまで無保存とは保証しません。

## Netlifyで設定する値

既存のMy Memoサイトを開き、Project configuration（旧Site configuration）→ Environment variablesから設定します。UI名称は変更される場合があります。**Functions用の実行時スコープ、Production context** に登録し、設定後は再デプロイしてください。キーをGitHub・チャット・`VITE_`変数に入れないでください。

| 変数 | 値 |
|---|---|
| `AI_ENABLED` | 設定・費用確認後に `true`。停止する場合 `false` |
| `OPENAI_API_KEY` | OpenAIの専用プロジェクトで発行したAPIキー |
| `OPENAI_MODEL` | `gpt-4.1-mini`（既定）、または `gpt-4.1-nano` |
| `AI_ALLOWED_ORIGIN` | `https://gentle-souffle-0c93dc.netlify.app` |
| `UPSTASH_REDIS_REST_URL` | RedisデータベースのHTTPS REST URL（`.upstash.io`） |
| `UPSTASH_REDIS_REST_TOKEN` | そのデータベースの読み書きRESTトークン |
| `AI_RATE_SALT` | ランダムな32文字以上の秘密値。例：自分の端末で `openssl rand -hex 32` を実行して生成 |
| `AI_DAILY_LIMIT` | サイト全体の1日上限。既定20、最大200 |
| `AI_IP_DAILY_LIMIT` | 接続元IPごとの1日上限。既定5、最大20 |

Upstashはこのサイト専用DBを推奨します。共有DBでは同じキー接頭辞を使う別アプリと利用回数が合算されます。OpenAIのプロジェクト予算・アラート、NetlifyとUpstashの支出上限（各プランが提供する場合）も設定してください。予算アラートだけを強制停止と考えないでください。

## 利用回数制限

RedisのLuaスクリプトで、サイト全体・IPごとの日次回数と10秒の連続実行制限を一度に更新します。インスタンスをまたいで適用され、Redisが未設定・障害の場合はAI呼び出しを停止します。日次枠はUTC 0時（日本時間9時）更新。予約した回数はAPIエラー・キャンセル時も消費します。キーは48時間以内、連続実行キーは10秒で失効します。

Netlifyが提供する接続元IPを秘密ソルトとハッシュ化して計数し、生のIP・文章はRedisに保存しません。家族や学校など同じIPは枠を共有します。現在のアプリには認証がないため、これは会員別の制限ではありません。Origin検査は認証の代わりにはならず、公開APIに第三者がリクエストして利用枠を消費する可能性は残ります。サイト全体の上限でAIへの呼び出し数を抑えますが、Netlify/Redisへの大量アクセス料金まで防ぐものではありません。一般公開を拡大する際はプラットフォーム側のトラフィック制限や認証を別途検討してください。

## デプロイと確認

1. 既存サイトと連携しているGitHubブランチをNetlify管理画面で確認します。これまでの公開対象は `release/my-memo` です。
2. 上記の環境変数を登録し、そのブランチの最新コミットをデプロイします。既存URLを維持してください。新しいURLでは端末内データの保存領域が別になります。
3. `https://gentle-souffle-0c93dc.netlify.app/.netlify/functions/ai` を開き、JSONの `available: true` を確認します。これは設定値の存在確認で、キーの有効性や残高の保証ではありません。秘密値は表示されません。
4. 個人情報のないテストメモで、日本語・英語の要約、ビジネス/教授向けの文章、尊敬語/謙譲語、校正、翻訳を実生成して品質を確認します。
5. 赤・青など複数の色を付け、AI結果の色、選択範囲外の保持、置き換え後のUndo/Redo、保存後の再読み込みを確認します。結果を見て「コピー」「メモに挿入」「元の文章と置き換え」を選びます。
6. iPhone Safariとホーム画面PWA、ライト/ダーク、キーボード表示中で、AI・ToDo・共有・Undoのタップ領域を確認します。

オフラインでは生成できません。原文を保存してから送信し、結果を反映する直前にも原文と保存済み本文・色を照合します。別タブ等で変わっていれば適用を拒否します。キャンセルは原文を変えず通信を中止しますが、既に始まった外部処理の停止・返金は保証できません。

## 装飾・結果の制約

既存エディタはプレーンテキストと6色の範囲情報を使っています。太字・下線は既存機能にないため、この変更では追加していません。色付き文字はトークンに置き換え、サーバーとクライアントの両方で欠落・重複・改変を検査し、元の文字列と色を復元します。位置は変わる場合があります。保護範囲が長い場合は短い要約より保持を優先します。翻訳時も色付き部分は原文の言語で残ります。保護トークン形式を含む本文、色の範囲が128個を超える選択範囲は拒否します。

AIは事実・数字・意味を完全に保持するとは保証できません。自動テストはAPI応答のテスト用データによる安全性検証で、実生成の品質検証の代わりではありません。生成結果のHTMLは実行しません。コピーはプレーンテキスト、アプリ内への挿入・置換は文字色も保持します。
